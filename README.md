# ดาวและกลุ่มดาวในกล้องดูดาว

- ดาวจริง **470 ดวง** อยู่ตำแหน่งเดียวกับบนฟ้าจริง
- ดาวประกอบฉากอีก 420 ดวง (สุ่มขึ้นมาให้ฟ้าดูเต็ม ไม่ใช่ดาวจริง) รวมบนฟ้า 890 ดวง
- กลุ่มดาว **62 กลุ่ม**
- วัตถุให้ส่องด้วยกล้อง **8 อย่าง**

ฟ้าหมุนตามเวลาและฤดูเหมือนฟ้าจริง แต่ละคืนจึงเห็นกลุ่มดาวไม่เหมือนกัน
ไม่มีกลุ่มดาวฟ้าซีกใต้ เช่น กางเขนใต้ เพราะจากตำแหน่งเมืองในเกมมองเห็นไม่ครบทั้งกลุ่ม
